# Project NOMAD datasets

Copied from https://github.com/crosstalk-solutions/project-nomad, folder `collections/`, commit 54ee30a, under the Apache License 2.0 (LICENSE in this folder).

- `natural_remedies.json`: 18 herbs, summarising NIH NCCIH "Herbs at a Glance"
- `home_remedies.json`: 20 home measures, summarising CDC, NIH, MedlinePlus and FDA pages
- `conditions.json`: the conditions they are used for

`tools/import-nomad.js` turns them into kb/ entries. Not yet run.
